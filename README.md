# iouring_cas_threadPool

假设现在是在开发高性能服务器的一个模块。这里要实现的功能接受高并发的请求，并且需要快速地处理这些请求。
自上而下，
第一，对于 IO 部分，当前阶段优先使用 epoll 完成“接入-切帧-入队-执行”闭环，io_uring 作为后续演进项暂缓。
第二，关于任务队列的实现，使用环形缓冲区存储任务，并通过 CAS 操作管理队列头尾指针。
第三，线程池中的线程通过 CAS 操作获取任务并执行，减少锁竞争并提升并发处理效率。
第四，当前阶段执行器采用容量模式（CapacityModeExecutor）：仅做轻量 payload 读取与头字段解析，不做回包与外部 IO，用于评估接入模块承载能力上限。

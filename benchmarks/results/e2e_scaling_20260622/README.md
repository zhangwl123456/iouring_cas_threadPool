# 端到端补充测试 (2026-06-22)

## 测试目标

在 6-20 日维度测试基础上，针对"连接数 8 + payload 256B"的特定参数组合进行重复性验证，为后续规范化采样提供参考。

| 参数 | 值 |
|-----|------|
| tasks | 20000 |
| threads | 4 |
| queue_capacity | 8192 |
| payload_bytes | 256 |
| client_connections | 8 |
| 环境 | Codespace (4 vCPU, 15 GiB) |
| 测试方式 | 多轮单次采样 (r1, r2, r3, ...) |

## 关键发现

- **波动范围大**: 连续 3 轮测试吞吐跨度 181k~266k tps（47% 波动），反映 Codespace 共享环境的噪声特性
- **参数对标**: conn8 + payload256 的性能介于：
  - conn8 + payload128 (277.8k) 和
  - conn4 + payload256 (219.8k) 之间
- **链路完整性**: 所有轮次均通过零容错验证

## 与历史对比

与 2026-06-20 的维度测试对标：
- conn8 + payload128：277.8k tps (历史)
- conn8 + payload256：~223k tps (本次补充, 多轮均值)
- 差异原因：payload 增大 2 倍导致任务级吞吐下降，但字节级吞吐不一定下降

## 后续用途

本测试结果作为 2026-06-22 SPEC 规范化采样（e2e_spec_compliant_20260622）的参考，后者采用"1 轮预热 + 5 轮正式采样"的标准化协议。
